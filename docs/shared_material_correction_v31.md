# v31 第一阶段：共享特征学习材料补偿幅值

本轮已实现并训练最终网络阶段的材料补偿读出头，三例完整 GPU 任务检查通过。它替换每个物理子步中最后一次解析材料响应；两轮解析预测及其材料补偿保留。默认入口仍使用已发布的 v24 权重，新实验通过单独 recipe 启用。

## 网络与实际省去的计算

父模型的 648 维共享主干冻结，所有父权重张量已逐一验证不变。新增读出头共 253,400 个可训练参数，复用当次主干 latent，不增加共享主干前向次数。

- 对当前材料对象的节点 latent 作质量加权汇聚，并进行 LayerNorm。
- 附加 50 维无量纲特征：局部响应和当前提议的 24 维模态摘要，以及幅值尺度与 dt。局部摘要经固定尺度归一化，有独立线性读出旁路。
- 一个 256/256 隐层 MLP 输出 24 个材料模态系数；对象共享相同权重，输入不包含 demo 名称或任意 object_id 数值编码。
- 材料基随材料参考选定的两条方向转动，保留当前几何、质量和去刚体运动构造。参考方向选择已使用 GPU gather，避免为两个索引取回 CPU 标量。

记 H 为当前冻结正度量，Q 为既有受保护基，B 为材料基，σ 为廉价响应尺度。实际预测为：

`d_material = (I - Q Qᵀ H) [σ B cθ(shared_latent, local_features)]`

主干和其他物理分支先生成提议，新材料位移与提议融合后，仍经过原来的切空间、运动、接触激活、几何与接受检查。H 不等于完整非线性 Hessian；这里保留已有投影，也没有重新定义材料刚度或摩擦。

单材料块的原 `correct` 需要两次 24 列 H 作用、一次当前提议的 H 作用以及材料能量 Gram 的谱求解。新路径保留一次提议向量的 H 作用和一次预测向量投影，不构建该 24 列能量 Gram，不在线求材料响应系数。**材料基本身的六维质量谱运算、主流程粗空间及局部逆仍然存在。**

因此每输出帧的解析材料求解从九次降为六次，另三次由读出头替代；物理响应装配仍为九次。不能把这一计数变化称为全部物理计算减少三分之一。

## 标签、训练与平台停止

使用原默认模型独立完成 Franka 软块、单角抓布、W1 装袋三条完整轨迹。在最终网络阶段，由当前状态上的解析材料补偿产生离线标签，每隔两次神经阶段采一个样本。没有用完整 VBD 在部署时修正状态。

| 轨迹 | 样本 |
|---|---:|
| Franka 软块 | 405 |
| 单角抓布 | 252 |
| W1 装袋 | 439 |
| 合计 | 1,096 |

训练 877 个样本，验证 219 个样本，按连续时间块留出。它们来自相同的三个资产和材料配置，**不是独立资产/材料泛化验证**。本轮训练冻结主干，仅验证在已有共享特征上是否可以学习这个模块；联合微调主干尚未开展。

离线标签保存投影材料基的质量 Gram、与实际教师位移的内积及目标范数。它们只用于计算实际广义位移误差，不作为部署输入，也不把有歧义的模态系数 MSE 当作主目标。旋转分量用质量乘长度平方进行单位归一化，这个监督范数不声称等于精确惯量能量。

初次 GPU 布料诊断发现，质量 Gram 使用 1e-10 截断会丢掉近乎平面模式，留下约 1.08% 的相对表示误差，绝对 RMS 约 0.12 微米。将**离线表示检查**的截断改为 1e-12 后，完整布料标签的最大相对表示误差约 2.1e-14。解析教师能量系统的截断与部署物理门槛没有修改；诊断失败保留在本地结果中。

训练最多预算 600 次更新，验证损失进入平台后在第 320 次停止，保留第 220 次的最佳验证权重。主损失从 0.9918 降至 0.4738，聚合的归一化平方位移误差相对省略材料补偿的基线从 1 降至 0.3531。损失有明显波动，不宣称严格收敛或逐状态准确。

## 完整 GPU 验证

| 场景 | 帧数 | 网络调用 | 剩余解析材料求解 | 学习替代调用 | 原任务检查 | 录制循环 FPS |
|---|---:|---:|---:|---:|---|---:|
| Franka 软块 | 270 | 810 | 1,620 | 810 | PASS | 1.24 |
| 单角抓布 | 168 | 504 | 1,008 | 504 | PASS | 1.15 |
| W1 装袋 | 288 | 877 | 1,754 | 877 | PASS | 1.06 |

三例均零重试、零原生 VBD/Featherstone 步进、零教师轨迹读取。Franka 完成整块离桌与保持，最小四面体体积比约 0.617，最大机器人/软块表面重叠约 0.125 mm。抓布末段宽度比 0.853、原门槛 0.55，最大机器人/布料表面重叠约 0.478 mm。W1 末段检查的方块角点均留在实际袋壳内，双侧抓袋接触采样比例为 100%，可见变形检查通过。

这些 FPS 包含录制循环内首次编译、碰撞、物理、同步和记录，不完整包含前置初始化，也不含渲染；前一例的 CPU 审核/渲染可能与下一例推理重叠。采集标签的父模型还额外做了离线投影/谱诊断，其计时不能当作普通父模型推理基准。不能用上表对历史 FPS 或采集时间直接求加速比。

在相同 Franka 保持状态、权重、latent 和物理度量下，七样本交错的材料模块热运行中位数为解析 3.43 ms、学习 3.01 ms，耗时降低约 12.1%。这是单模块、单状态结果，**不是整帧提速 12.1%**。这个保持状态上，材料补偿本身极小，学习误差的相对平方比为 1.75，最大绝对提议差仅约 0.048 微米；因此不能声称新头在每个状态都优于零补偿。

本轮没有完整比较“直接省略最终材料补偿”的任务与性能，尚未证明新头相对这个更便宜的选项的整体优势。也没有验证 A1+N1、未见材料、其他三个机器人场景或全部纯 VBD demo。全轨迹与解析基线存在算法性差异，不要求严格数值相同，原任务和物理门槛保留。

```bash
export WP_VBD_NEWTON_ROOT="$PWD/.local/newton_pinned_25298"
export TORCHINDUCTOR_CACHE_DIR="$PWD/.local/p0/torchinductor"

# 用已采集且绑定哈希的数据重训；输出目录须尚不存在。
.venv/bin/python scripts/train_shared_material.py \
  --data outputs/material_v31/data/franka outputs/material_v31/data/cloth_rank12 outputs/material_v31/data/w1 \
  --output outputs/material_v31_retrain --updates 600 --learning-rate .0007

# 显式新权重 GPU 开窗；scene 也可选 cloth / w1。
.venv/bin/python scripts/run_robot_validation.py --scene franka \
  --recipe outputs/material_v31/train_main/recipe.json --window

# 只关闭新头、恢复最终解析材料求解，原共享响应保持开启。
.venv/bin/python scripts/run_robot_validation.py --scene franka \
  --recipe outputs/material_v31/train_main/recipe.json \
  --no-shared-material-correction --output outputs/my_v31_analytic_ablation
```

权重位于 `outputs/material_v31/train_main/model.pt`，另保留读出头优化器、随机数状态、数据哈希、训练划分、父权重哈希及实现快照。当前默认入口没有切换到这份实验权重。

下一阶段应先增加省略最终补偿的对照，再做主干与读出头联合训练，在明确模块监督和滚动监督下尝试 A1+N1。删除整轮重复物理响应才可能带来更明显的端到端收益；不能仅在推理中删一轮解析或放大 dt。
