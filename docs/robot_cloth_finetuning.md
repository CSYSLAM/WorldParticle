# 单角抓布的大步长微调

这轮保留共享 648 维网络及原检查点，目标仍为每显示帧三子步、每子步两轮解析预测和一次网络校正。六子步只用于诊断，不作为修复完成的证据。

## 已定位的偏差

原始整边折起资产在旧网络的三子步推理中会逐渐卷成窄束；面积和抓取成功不足以验收布的变形。相同资产的三子步纯解析对照也会卷曲，六子步解析对照明显改善。关闭旧网络的末端速度头只能部分改善，不能单独解决问题。

因此针对大步长的位移、速度及长期形状误差微调共享网络，同时保留解析材料方向。不能将偏差完全归因于某个网络头，也不能据此宣称网络优于纯解析流程。

## 数据与监督

`collect_robot_cloth_substeps.py` 独立运行原生 VBD，完整记录 2.8 秒机器人抓布、抬升及悬垂过程。参考步长为 1/720 秒，32 次原生迭代；显式采用每个物理步最后一次迭代执行 mimic 投影的参考数值策略。该策略只用于离线教师，不进入推理。

最多采集 12 个材料、摩擦及初始折角组合。训练和开发材料独立；未通过抓取、网格伸长、mimic 误差及末段下垂外观检查的轨迹不进入训练。每条保存实际细步速度、姿态、电机输入、冻结源资产和校验摘要；不通过位置差分伪造教师速度。

`robot_cloth_data.py` 在不构建动力学求解器的条件下恢复资产并核验静态字段。四个细步对应一个 1/180 秒学生步，已记录的控制输入按其持续时间归并。推理不读取教师状态。

`train_robot_cloth_corrector.py` 微调共享主干和共享末端速度头，不新增仅针对此演示的运动脚本。默认连续预测 24 个物理步，其间不把状态重置为教师值；每四步截断反向传播，前向状态及接触历史继续使用预测值。混入十类已有训练数据，并回放已分区的机器人软体参考。

原有位置、速度、动量、应变、周期弯曲角和接触损失之外，`ClothRolloutObjective` 加入教师相对的布面法向、非局部点对距离及去除整体平移后的多余动能损失。目标来自教师的可变形形状，不强制平整或让整块布跟随手掌。

## 验收

固定独立开发窗口比较新旧权重，同时观察已有类型的回放误差；进入平台后提前停止。保留旧检查点，开发集和回放误差未同时改善时不自动选为有效版本。

窗口 loss 下降只是训练信号。最终还需用新权重从初始状态完整运行三子步抓布，检查实际网络调用数、抓取、接触、伸长和末段布面宽度/法向一致性，并人工查看视频。原整边折起案例应保留为对照，不能只通过换初始几何规避问题。以上脚本与验收设计的存在，不表示新权重已经训练完成或通过完整场景。

## 本轮已完成的结果

本地结果目录为 `.local/cloth_finetune/`。12 个完整教师组合中，6 条训练轨迹和 1 条独立材料开发轨迹通过筛选，5 条未通过下垂检查而排除。完成 40 次更新，选中 `train/selected.pt`；固定开发窗口 loss 从 0.609319 降至 0.515227（下降 15.4%），十类已有对象的固定回放 loss 从 0.514691 降至 0.506694。主干首层注意力、响应读出及末端速度读出的权重均有实际变化。训练期间原生动力学调用为零。

原整边折起资产 `model_edge/` 已完整运行 2.8 秒、168 帧，实际 504 次网络前向、504 个物理步，零拒绝重试，169 个保存状态的审计通过。末帧面板宽度比由旧权重的 0.41049 提升至 0.64399，法向一致性由 0.51159 提升至 0.75748，严重面板折边由 11 条降为 1 条。末 0.4 秒最低宽度比 0.64391、最低一致性 0.75431，均超过原定阈值。

布角抬升 298.8 mm，悬停期双侧抓角接触比例 100%，最大主拉伸 1.133，机器人–布面重叠峰值约 0.341 mm。初始资产、材料、夹取控制和解析轮数均沿用旧场景；未使用布节点固定、附着、教师轨迹或原生求解器推进。这些结果只覆盖该抓布实例；其余完整机器人场景的复核单独记录，不能用短窗口回放代替。

同 GPU 的当前代码消融 `physical_edge/` 保留三轮物理响应、关闭网络，完整运行 168 帧，网络调用为零。末帧面板宽度比 0.25454、法向一致性 0.43758、严重折边 36 条。三组录像（历史旧网络、当前纯解析、当前微调网络）的初始粒子、初始刚体姿态、三角网格和所有电机目标逐元素完全相同。该对照支持网络对本例变形的实际贡献，但不证明跨全部场景的必要性或相对原生 VBD 的速度优势。对照图和数值为 `network_ablation.png`、`network_ablation.json`；完整视频为 `franka_cloth_finetuned.mp4`。

同一新权重已完成两项机器人回归：Franka 软块抓取、抬升和保持共 270 帧、810 次网络调用、零重试，保持期整块材料离桌至少 112 mm，全程四面体体积比 0.625–1.082。此项没有测试张爪释放。W1 完整装袋共 288 帧、877 次网络调用、零重试，包含少量沿用原有策略的自适应细分（最短接受步 1/360 秒），最终方块包含和左手双侧接触检查通过。W1 记录的全部电机目标与旧成功用例逐元素一致。

旧 v24 配方保留；新权重配方为 `configs/robot_validation_cloth_ft.json`，固定权重摘要和各场景参数。W1 显式保留原先的 warm-start 策略，不因新检查点携带的默认配置而意外切换物理策略。下面命令从项目根目录执行，`--scene` 可换为 `franka` 或 `w1`：

```bash
.venv/bin/python scripts/run_robot_validation.py \
  --scene cloth --recipe configs/robot_validation_cloth_ft.json --render
```

统一验收结果为 `.local/cloth_finetune/final_review.json`。本轮没有全量重验全部 42 个官方用例。
