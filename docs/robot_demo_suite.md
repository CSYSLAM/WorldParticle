# 当前共享权重的六个机器人场景

统一检查点为 `model_releases/shared_vbd_v24_cloth40/model.pt`，SHA256 为 `1aac9909419fbb8dda7beef4f0d533050d4ce4191849ebd54ba37dd6a85a2132`。六个场景使用同一份权重，不为各场景更换模型。

| 场景名 | 内容 | 名义子步/显示帧 |
|---|---|---:|
| `franka` | 软块抓取、抬升、保持 | 3 |
| `w1` | 左手持柔性袋，右手放块入袋 | 3 |
| `cloth` | 从上方夹起自由布角 | 3 |
| `piper` | 抓软块并放到自由刚体块上 | 3 |
| `w1_dual` | 左手刚体圆柱、右手软球，无垫块侧夹 | 3 |
| `franka_rigid_cloth` | 抓刚体、搬运并释放到可变形布上 | 3 |

每个物理步是两轮解析预测、一次网络校正，保留解析材料剩余误差修正。困难接触允许沿用有界自适应细分，最短接受步 1/600 秒；实际接受步数、网络调用和重试必须按 `run.json` 统计，不能把名义三子步说成每帧严格三次调用。

旧双手入口已接入当前的接受接触历史、周期弯曲、mimic 度量投影、0.012 m 运动检测范围和自适应步长。刚体放布入口显式传递三子步和当前材料运动模式。没有用恢复到十子步作为默认迁移方案，也不通过附着、物体位姿脚本或教师轨迹推进任务。

从项目根目录运行一个场景，结束后生成视频：

```bash
.venv/bin/python scripts/run_robot_validation.py --scene cloth --render
```

六个入口都支持 `--window`；例如边推理边显示 W1 装袋：

```bash
.venv/bin/python scripts/run_robot_validation.py --scene w1 --window
```

窗口每完成一帧推理就更新一次，显示功能不提高仿真推进速度。关窗会保留已接受的状态，未跑完整段时不标记完成。

批量生成六个视频到一个文件夹：

```bash
.venv/bin/python scripts/run_robot_demo_suite.py --output outputs/my_robot_suite
```

输出目录须为新目录。视频统一放在输出目录的 `videos/`，原始状态在 `recordings/`，执行信息在 `manifest.json`。批量入口只标记录制完成，任务和视觉验收需另看各场景审计及视频。加 `--dry-run` 可以只打印命令；加 `--cases piper w1_dual` 可以指定子集。

本轮已验证轨迹复用和新录制的汇总目录为 `outputs/current_weight_demos_20261120/`，其 `manifest.json` 明确区分复用的同权重结果与新录制结果。

六例完整视频均已通过检查：Franka 软块 810 次、W1 装袋 877 次、抓布 504 次、Piper 936 次、W1 双手侧夹 540 次、刚体放布 1152 次网络调用，全部零重试。W1 装袋较名义三子步有 13 个接受细分步，其余严格三次/显示帧。新增抓布、Piper、装袋的开窗入口均已在 GPU 上实际运行一帧并检查三次网络调用。

刚体放布在迁移时需要将**刚体接触**的数值切向支撑从 1 改为 64；软接触支撑仍为 8，质量、摩擦 1.5 和库仑上限公式不变，解析预测和网络调用轮数未增加。修正版完整搬运 26.0 cm，松爪后有实际布面支撑接触，布中心额外下垂 5.5 mm，最大刚体表面重叠约 1.20 mm。失败试跑只保留简短诊断摘要，不混入六段交付视频。
