# 基于 WorldParticle 逐步替代 VBD 的训练推理与验证方案

> v4.1 完整执行版。整合 v4 与最终可行性审查；供 agent 按阶段实现、训练与独立验收。

本方案用于指导 agent 逐步实现基于 WorldParticle 的统一学习型动力学求解器，覆盖软体、布料、刚体、机器人关节和 cable/rod，并实现材料参数可控、共享权重、双向耦合及有明确适用条件的无穿透更新。

执行原则：先建立可信基线、数据和独立验证器，再逐项扩展新求解器。动力学由可学习网络和明确列出的物理算子共同推进；允许解析积分、本构计算、小块局部求解和有限约束修正，但不接入完整 VBD 迭代链、补迭代或失败回退。VBD 可作为离线教师与独立评测基线，其有价值的局部机制可拆成新架构内部组件。零穿透、动力学正确、参数可控、加速是四个独立验收项。

版本：方案 v4.1。各阶段初始状态均为 NOT_STARTED；本文件是执行计划，不表示代码、训练或保证已经完成。采用网络与物理算子协同求解；完整 VBD 不参与部署步进、补迭代或回退。第 4.4–4.14 节规定网络、物理分支、稳定化及展开接口。本版整合 v4 与最后一次可行性审查，新增同步更新稳定化、DAT 运动预算可达性、关节累计转角三项要求。机器人范围严格限定为 P0 固定版本 VBD 实际支持的关节与行为。

开工判断：可启动 P0–P3；进入 P4 前，必须完成本版三项新增检查。共享权重、参数控制与混合求解在架构上可行；有限预算下同时达到精度、可靠性和加速目标，仍须用实验验证。

## 1 成功定义与范围

### 1.1 新求解器与完整 VBD 的边界

| 环节 | 允许的计算 | 边界 |
| --- | --- | --- |
| 离线监督 | VBD 参考轨迹、训练状态标签、教师更新 | 与部署步进隔离 |
| 物理分支 | 外力积分、本构能量/残差、质量惯量、明确预算的小块局部求解 | 模块级拆分，不调用完整 VBD step 或收敛循环 |
| 网络分支 | 共享 WorldParticle 学习全局耦合、更新修正与条件化 | 与物理分支共同生成动力学更新 |
| 几何与约束层 | DAT、合法自由度更新、有限预算的接触/关节局部运算 | 所有几何修正受同一可行路径合约约束 |
| 独立评测 | VBD 单独运行产生基线 | 不修正被测轨迹 |

部署只运行本文定义的新求解器，不提供完整 VBD 辅助或回退模式。每个物理算子登记功能、输入输出、局部规模、调用次数与耗时；允许借鉴或封装 VBD 的局部数学计算，不允许把整套 VBD 求解藏在一个物理层中。失败时在已验证的新求解器预算内重试或拒绝；训练教师查询只生成离线监督。

### 1.2 支持清单

建立逐项矩阵，行包含：软体、布料、自由刚体、固定版本 VBD 实际支持的全部关节类型及对应限位/驱动行为、该版本支持的机器人连接关系、rod 拉伸/剪切/弯曲/扭转、附件、自接触、刚柔接触、柔柔接触、刚刚接触。列包含：Newton/VBD 固定版本与证据、教师可用、数据覆盖、网络表示、推理实现、物理验证、几何保证、性能验收。关节清单以该版本 VBD 实现及运行测试为准，不能将 Newton 全局关节枚举或其他求解器的功能直接加入。

P0 输出并冻结 joint_scope.json：关节类型、自由度、锚点/轴、支持的限位/驱动/耦合行为、已知限制、源码位置及最小测试。只对这份 VBD 支持清单训练和验收。未知项标 UNKNOWN；VBD 明确不支持的项标 OUT_OF_SCOPE；VBD 支持但网络尚未实现的项标 NOT_IMPLEMENTED。闭链、mimic、特殊驱动等仅在所锁定 VBD 版本确实支持时纳入，不作为额外扩展目标。

### 1.3 物理与数值参数

物理参数包括材料、质量惯量、参考几何、关节、接触摩擦、驱动规律。数值参数包括时间步、迭代预算、DAT 松弛、接触检测预算。时间步影响离散动力学，必须输入或严格固定；迭代数不能伪装成材料软硬。

第一版使用确定性推理。参数改变导致行为改变，不使用随机采样决定材料响应。未知材料识别独立于前向动力学模型。

### P1 教师精度与独立物理基准

建立三个用途分离的参考：①同一时间步 h、相同离散模型下充分收敛的 VBD，作为下一步状态及离散残差的训练教师；②减小 h 并做时间步/求解收敛研究的高精度参考，用于检查时间离散误差和物理响应；③生产预算 VBD，用于公平比较速度与精度。增加迭代只控制求解误差，不消除时间离散误差。不得同时强迫网络精确匹配小时间步聚合轨迹、又让不同的大时间步离散方程残差为零。

验证算例：

- 软体：单四面体与块体拉伸、压缩、剪切，自由振动。

- 布料：面内拉伸、条带弯曲、悬垂和振动。

- 刚体：自由飞行、无外力旋转、解析摆、落体接触。

- rod：拉伸、悬臂弯曲、扭转；确认截面朝向和角速度。

- 关节：单自由度摆、双摆、限位、驱动跟踪、自由度锁定。

- 接触：薄壁高速冲击、堆叠、挤压、多层布、自接触、近乎平行边。

教师必须通过解析解、静力曲线、守恒/耗散或独立方法的交叉检验。先检查教师与目标无穿几何是否兼容：有限刚度接触可能允许接触偏置范围内的压缩，其定义必须与物理表面分开；若教师实际穿过本方案要求不可穿过的几何，必须修订参考配置或明确修改目标模型并重新生成相容标签，不得默默截断教师标签后仍称原 VBD 真值。DAT 只保证适用条件下的几何可行，不证明动力学准确。


交付：benchmarks/、reference_convergence.json、units_and_materials.md、metrics_spec.md、discrete_dynamics_spec.md、state_schema.md、joint_history_spec.md。

验收：同 h 教师的求解误差建议不超过模型相应验收容差的 20%；时间离散偏差另报。达不到时缩小范围或修教师，禁止训练错误标签。

#### 离散动力学目标必须先冻结

discrete_dynamics_spec.md 必须列出：位置/姿态与速度的时刻约定、积分器及 h、惯性项、外力和驱动的评价时刻、本构与阻尼、接触法向/摩擦定律、关节及附件的柔顺定律、内部状态演化、累计关节角与分支跟踪、初值/热启动及收敛判据。残差算子、数据生成器、速度恢复和验收器共同引用该规格，不得各自实现一套近似定义。

同一时间步的求解变量为候选位置/姿态及模型所需辅助变量。材料和摩擦含历史时，教师标签必须包含完整初始历史。保守能量梯度、非保守广义力、约束/互补残差应按具体模型组合；不得把所有摩擦和驱动强行改写成势能梯度。

分别记录物理刚度/阻尼 k、c 与数值惩罚/增广参数、稳定化量和迭代预算。网络输入物理参数的改变应改变目标方程；数值参数改变原则上只改变近似求解过程。若固定版本存在二者耦合，必须在审计中标明并给出教师收敛对照。

每帧数据：

- deformable 节点位置/速度。

- 外力、力矩、机器人动作、目标与施加区间。

- 时间步、控制采样时刻、驱动目标、接触候选/匹配 ID、接受路径、物理响应标签及其来源；同 h 教师标签与小 h 评测参考显式区分。

- 成功/失败状态、候选溢出、最小间距、反转、关节残差、教师收敛证据。

### 3.2 数据划分与生成

先生成每类约 20 个诊断场景，再到约 200 个 pilot 场景；正式规模由学习曲线决定。P2 同时建立少量软体、布料、两个关节刚体及数段 rod 的接口样例，P4 从小规模多类型共享模型起步；不把全部异构接口和共享权重问题留到后期。无需在 P2 实现复杂混合接触。

训练/验证/测试按对象家族、场景种子、拓扑、动作序列划分，例如 70/15/15。一个轨迹的相邻窗口不可跨集合。材料扫描的同源场景保持分组；额外设置专门的参数插值测试，并明确与形状泛化测试区别。

测试集分为：域内、参数组合留出、未见拓扑/形状、分辨率、接触压力测试、严格域外。训练前冻结测试清单。域外失败必须报告，不能自动承诺外推。

成对生成同几何、同外力、只改变一个物理参数的序列。对正刚度使用 log 采样；零刚度/零阻尼作为独立情况处理。参数范围来自 P1 稳定且有代表性的物理范围，不能无限扩大。归一化只使用训练集统计量。

质量控制：初始可行、参考状态合法、教师收敛、无 NaN、检测无溢出；状态历史完整且时间对齐。保留失败数据及原因用于诊断，不能混入正确轨迹标签。

### 3.3 状态、历史与数值辅助变量的生命周期

| 类别 | 典型字段 | 更新与持久化规则 |
| --- | --- | --- |
| 物理状态 | 位置/姿态、速度/角速度、模型已有的材料内部变量 | 材料历史以时间步起点为基准评价候选状态；接受整步后提交一次，禁止 K 轮重复累积物理老化/损伤 |
| 关节历史 | 展开角、累计转数或等价分支跟踪量、参考偏置 | 按固定版本语义评价候选和提交整步；拒绝时回滚，重启时恢复，不能在 K 轮中重复累计相同转角 |
| 接触历史 | 接触匹配 ID、切向参考/粘着锚点、选定摩擦模型需要的历史 | 规定新建、持续、分离、重匹配、坐标运输和清除；仅在接受的状态上更新/提交 |
| 数值状态 | 启用的乘子、惩罚参数、热启动量、局部预条件信息 | 写明单位、残差角色、固定预算更新公式及重置条件；可跨步热启动但必须可序列化，不冒充材料属性 |
| 临时网络状态 | latent、当前候选、截断反馈 | 首版每时间步重建；每轮覆盖或更新，拒绝的试探不得污染已提交状态 |

为每个持久字段列出 owner、shape、单位、初始化、更新频率及失效条件。接触匹配不能仅依赖数组下标；固定拓扑下采用稳定的几何特征标识，并测试滑移、断接触及再次接触。材料/拓扑/过滤变化需显式失效相应缓存。

若使用局部乘子/约束更新，每轮执行预先登记的有界次数，作为新求解器的一部分计时；不运行完整 VBD 的增广迭代链。若省略某个历史或辅助量，必须证明目标模型不依赖它，或声明并验证模型变更。

数据保存与恢复必须通过“从快照重启得到相同后续轨迹”的确定性测试。离线查询教师时，把物理历史与摩擦状态按已审计映射传给教师；教师内部数值状态按固定策略初始化并求解，不把新求解器的未知乘子直接当成相容热启动。拒绝整步时回滚全部持久状态和仿真时间。

#### 3.3.1 关节累计转角

P0 审计固定 VBD 版本是否对 REVOLUTE、单角自由度 D6 等支持绕圈跟踪；只纳入实际支持项目。姿态相同不一定代表关节状态相同，不能用 principal angle 覆盖具有历史意义的展开角。

joint_history_spec.md 必须规定表示法、参考帧、候选分支选择、整步提交、重置和快照恢复。候选角从已接受分支一致地求值；内部 K 轮不等于经过 K 个物理时间步，不得反复累计从同一起点计算的同一增量。

验收包括跨越 ±π、连续多圈、相同姿态但不同累计角的驱动/限位响应、保存恢复连续性及拒绝回滚。固定源码若规定单步相对转角上限，须覆盖预测和内部修正并写入支持域；不将四元数合法等同于绕圈跟踪正确。

参考：[Newton SolverVBD 关节与角度跟踪说明](https://newton-physics.github.io/newton/latest/api/_generated/newton.solvers.SolverVBD.html)。最终以 P0 的固定 commit 为准。

## 4 网络架构与材料控制

### 4.1 保留和扩展 WorldParticle

保留局部交互编码、动态 super-token 编码及解码；不默认它具有线性复杂度。先测全分辨率注意力、merge 和碰撞成本，再决定稀疏化。

输入 token 类型：

- 节点 token：软体/布料状态。

- body/segment token：刚体与 rod 段位姿和速度。

- 结构关系：材料单元、弯曲边、杆段连接。

- joint/attachment token：关节及绑定关系。

- contact token：完整分辨率的接触特征及双方状态。

不同类型编码到共享隐空间；主干参数共享。输出为节点位移、刚体平移/旋转增量、rod 自由度增量。旋转采用明确的 SO(3) 更新，不直接任意相加 quaternion。刚体表面点由位姿生成，不独立预测。

精确碰撞几何不经 super-token 压缩。接触分支包含间距、厚度、法向、相对速度、双方质量材料、上轮截断反馈。跨对象双向传递，禁止把动态对象默认当静态边界。

### 4.2 材料条件化

第一版：显式物理参数输入＋特征调制。软体可用 E、nu、rho、阻尼，也可用 mu、lambda；锁定转换、本构、参考体积及离散规则。布料分离面内与弯曲，rod 分离拉伸/剪切/弯曲/扭转；若源码接收的是离散刚度而非连续材料常数，必须记录换算，不能把两者直接等同。条件编码器输出 FiLM 或低秩调制量，不替用户随机预测材料。

升级版：对象/单元级条件编码 z，经小网络生成低秩权重调制系数：
W(z) = W0 + A diag(g(z)) B。
所有 W0、A、B 和条件器跨类别联合训练；仅有效权重随物理输入变化。禁止直接平均独立 checkpoint。

异质材料保留逐单元特征并通过关系编码；不能把交界面属性简单均值化。材料、接触与关节参数分别条件化对应关系。一个共享 checkpoint 可包含类型 encoder/head 和共享的条件网络；不要求不同 DOF 使用同一个输出维度，也不得按场景切换独立训练的权重。

非线性响应需要形变状态；黏弹性/塑性需要内部状态。温度等影响必须明确作为参数或状态进入。第一版仅覆盖教师中已定义的本构，不凭空宣称支持损伤、塑性或热耦合。

### 4.3 两条候选模型

A：原始风格的轨迹残差预测。输入状态、材料和外力，预测下一步运动提议；用于比较纯学习与混合路线的学习能力和成本，不是进入主路线的必经阶段。

B：物理与学习协同更新。解析计算惯性/外力目标、本构/关节/接触残差及小块局部响应，WorldParticle 学习跨局部块耦合修正；融合后经 DAT 接受更新。第 4.4–4.13 节为首选原型，P2 先验证物理与异构接口，P4 再接共享网络；不运行完整 VBD 收敛循环。

A 是消融基线，B 是主线。先冻结离散目标和状态/算子契约，再验证 P2 局部物理基线与 P3 几何模块。所有局部求解、残差、检测、条件编码和保护计算计入成本；不能仅统计网络时间。

### 4.4 首选架构及模块契约

本节为待实现的明确原型。采用“解析预测＋局部物理更新＋WorldParticle 耦合修正＋DAT”，内部展开 K 个共享参数块。固定计算也参与动力学推进；网络承担局部物理块难以直接表达的非局部耦合及剩余误差。它不要求每个更新分量都由网络产生。

| 原 WorldParticle 部位 | 改造 | 首版是否可学习 |
| --- | --- | --- |
| 外力 predictor | 按离散规格构造惯性目标；只预计算应冻结的外力/命令，状态相关驱动力在残差中重算 | 否 |
| particle tokenizer | 增加 DOF 类型、结构/joint/contact 关系、物理参数、局部残差与历史特征 | 是；物理特征解析计算 |
| super-token encoder | 保留层次合并，加入类型、批次及物理交互分量隔离 | 是 |
| decoder | 保留实体到 super-token 查询，增加全分辨率局部接触/关节旁路 | 是 |
| 输出 head | 节点/刚体/杆段 head，预测具有尺度约束的耦合修正 | 是；根保持版本与自由修正对照 |
| physical branch | 从同一候选状态计算残差、局部度量、小块响应和明确的辅助量更新 | 首版固定 |
| fusion | 同尺度合成物理与网络提议，所有类型一起接受几何检查 | 同尺度相加后有界松弛；门控另作消融 |

所有对象在同一交互图中计算。contact/joint 是关系，不额外复制相连对象的自由度。物理分支与网络分支先各自读取同一状态快照，再融合、接受一次几何更新。

### 4.5 张量与关系编码

用 packed/ragged batch 表示变长场景。N 为独立 DOF 块数量，R 为关系数量，d 首版取 128。每个场景有独立 batch_id；任何 attention、merge、邻域或聚合都不得跨场景。

- node_state：节点 x、v，各为 [N_node,3]；参考几何单独保留。

- body_state：刚体/rod 段平移 [N_body,3]、旋转 [N_body,4]、线角速度各 [N_body,3]；明确 quaternion 约定。

- dof_type、object_id、dof_to_entity：类型、分组、索引映射。object_id 用于分组，不作为任意编号的数值 embedding。

- material_table：对象/面/体单元/杆段的材料向量及有效字段 mask。

- relation_data：关系类型、参与块索引、局部锚点、参考度量、材料、残差和 Jacobian 特征。

- dynamic_contact：候选几何对、参与块、重心权重/力臂、间距、法向、相对速度、摩擦、有效 mask。

- physical_features：每 DOF 的动力学残差 g、局部度量 B、提议 d_phys；关系级柔顺/接触/数值残差、可用的历史/乘子、上轮接受位移和截断反馈。完整残差 r 的定义来自离散规格；不能只用未计约束力的原始力梯度判断收敛。

- h：[N,d]；z：材料/环境条件编码；super_h：[M,d]。

四面体是四元关系，弯曲边和顶点–三角形接触也可能涉及多个节点。不得强行把所有关系压为两粒子边而丢失几何。先 relation encoder 聚合所有参与块，再按 incidence map 向各块 scatter；需保存法向、Jacobians 或权重的符号约定。

### 4.6 物理分支的明确职责

物理分支严格实现 P1 的离散动力学规格。惯性、材料、关节和接触响应在同一候选状态及指定历史下评价；摩擦不强行视为光滑保守势能。冻结控制命令和目标，不冻结依赖候选姿态/速度的 PD、阻尼或隐式驱动力；后者每轮按所选离散模型重算。外部控制策略只在控制时刻运行，不在 K 轮内重新采样动作。

每个 DOF 块 i 输出 g_i（含已定义辅助变量作用的广义动力学残差）、B_i（质量/时间步项与稳定化局部刚度度量）及 d_phys_i（小块线性运算的局部响应）。关系模块另输出柔顺定律、限位/接触及所需辅助变量方程的残差；完整 r 由这些项组成。存在约束或有限刚度时，原始几何偏差不等于完整数值残差。

节点可采用 3×3 块；自由刚体/rod 段可采用平移旋转 6×6 块。先进行长度和角度尺度变换，避免把米与弧度未经处理混入一个度量。固定/运动学自由度剔除或 mask，不靠伪质量处理。

示意更新：d_phys_i = -solve(B_i + eta_i I, g_i)，其中 eta 是按归一化块尺度定义的数值稳定化量，不是材料阻尼。它只是局部块提议，不等于完整 VBD 着色 Gauss–Seidel sweep；首版各块读取同一快照。B_i 按明确规则对称化/正定化，记录特征值下界、非有限量与条件数；旋转和平移先进行一致的尺度变换。稳定化不意味着原物理 Hessian 正定，也不保证全局收敛。

各块正定不能保证同步完整步稳定。局部提议先与网络修正融合，再按第 4.14 节使用有界松弛和明确的候选接受规则；数值稳定化 eta 与步幅松弛 omega 分别记录。

允许：本构力/刚度、质量惯量运算、有限大小局部求解、显式接触/关节残差。首版不加入额外的着色全局 sweep，不反复调用局部块直到传统残差收敛。任何后来增加的局部接触或约束迭代必须明确次数、作用与消融收益。

避免重复计算：外力、驱动、本构和接触各项有唯一的算子归属；网络学习融合更新仍存在的误差，不额外再加一份完整驱动冲量。训练主目标是接受后的状态及响应。若网络或 DAT 改变了运动，仅把解析分支的接触力输出为“总接触力”会失真；第 4.13 节规定响应测量与动量核对。

### 4.7 条件化局部 tokenizer

类型编码器 E_type 将节点或刚体映射到 d 维，输入当前候选状态、惯性目标差、质量/惯量、参考几何、h、物理参数、g/B 的归一化摘要、d_phys、接触历史和截断反馈。位置使用相对结构/交互信息；条件与运动量按第 4.13 节的单位/分辨率契约归一化，不把任意全场景统计量作为孤立物体的物理条件。

四条消息分支：

1. spatial：相对位置/速度的局部邻域。

2. structural：材料单元、布料弯曲、rod 连接，保留参考构型。

3. joint_attachment：关节类型、两侧锚点/轴、当前残差、驱动、限位。

4. contact：动态接触几何和双方响应特征。

每条关系先编码并向参与块聚合，随后与实体编码拼接，经线性投影回 [N,d]。同一种关系的参数跨对象共享。第一版用和/均值聚合并标明是否按度数归一化；缺失分支使用 mask，不用随意的物理零值冒充“参数为零”。

材料编码器 H(c) 输出 z。首版采用有界残差 FiLM：h_cond = (1 + a(z)) ⊙ LN(h) + b(z)，a/b 初始接近零。对象材料和关系材料分别调制实体 FFN 与关系 FFN。单元级材料异质性在关系中保留，不能只用对象平均刚度。

状态信息通过实体/关系特征进入主干；条件 z 由已知物理参数、明确的环境状态和 h 产生。温度或历史相关材料必须显式输入对应变量。控制命令是条件，候选状态相关驱动力由物理算子求值；材料编码不得从对象 ID 或场景标签猜材料。

### 4.8 Super-token 编码与全分辨率旁路

首版取 encoder 3 层，每层当前分辨率 self-attention 后合并，目标数量约为原来的一半；decoder 2 层。与官方 WorldParticle 深度/宽度不同，需标为缩小的研究变体。

合并只作用于 latent，不修改真实 DOF、碰撞几何或关系表。首版在同场景、同对象和同类 DOF 内合并，每个对象至少保留一个 token，记录实际 M。跨对象通信通过结构关系和保守潜在接触形成的交互分量进行；attention/归一化/池化都须避免不相互作用场景相互污染。候选图必须覆盖本步潜在接近，分量合并或拆分时更新 mask，不能为了隔离而丢掉即将发生的接触。

decoder 以原分辨率实体 token 查询 super tokens。每层同时注入未经压缩的 joint/contact 聚合特征，避免碰撞细节只经 coarse latent 传播。该旁路仍是可学习特征，几何保证由精确可行层负责。

位置编码使用一致的空间尺度。对象局部参考几何和空间相对几何分别编码。3D RoPE 或普通位置编码不自动保证旋转等变；先做整体平移/旋转测试和增强，若不足再替换成等变模块。

P2 先测物理和几何成本，P4 小模型立即测 token 编码、合并、attention、decoder 和内存成本；不得等扩展完才发现成本超预算。局部窗口/稀疏 attention 是后续可测的优化，需保持交互覆盖与精度；不预先宣称线性复杂度或百万粒子能力。

### 4.9 输出头与融合

共享 decoder 输出 h_i，经小型类型 head：

- 节点：3 维归一化位移修正。

- 刚体和 rod 段：6 维归一化平移/旋转切空间修正。

- 关节与接触不创建重复的位姿 DOF，通过关系消息与物理残差作用于相关实体；但其摩擦历史、乘子等辅助状态按第 3.3 节显式读写，不能理解为“完全无状态”。

- 内部材料状态第一版采用选定本构的解析更新；只有确有需要再加专门状态 head。

恢复物理尺度后先形成 d_raw = d_phys + d_net，再令 d_prop = omega_k d_raw，其中 0 < omega_k ≤ 1 是经过验证的数值松弛，不是材料参数。首版网络最后层零初始化，其初始行为等于采用相同松弛的局部基线。零初始化不保证训练后根保持或稳定；P4 比较自由修正与完整 r=0 时修正为零的版本。选择依据是第 4.13–4.14 节的固定点、稳定性、K 扫描及实际响应，不只看单步拟合误差。

可选升级：d_raw = alpha_i d_phys + beta_i d_net，d_prop = omega_k d_raw。alpha/beta 有界并报告分布；初始 alpha=1，beta 按非零可训练设计。omega 与分支门控的作用分开记录，禁止通过压低所有运动赢得几何指标。更复杂的学习预条件器暂不与动态权重同时引入。

所有更新先融合，再使用与 DOF 一致的路径参数化经过 DAT。刚体接受旋转增量按 Exp 映射更新；不能对表面粒子逐点截断后声称刚体性仍成立。

首版删除独立任意速度预测 head，采用与所选积分器一致的速度/角速度恢复及必要的接触速度处理。若后续保留 velocity head，需额外验证运动一致性与冲击响应，不能照搬位置保护后仍接受未经处理的速度。

### 4.10 网络块展开与训练计算图

固定时间步起点 s_t、h、已采样控制命令/目标及按积分器应冻结的外力。物理历史以 s_t 为基准评价候选；状态相关驱动、阻尼和接触每轮重新求值。每轮 k：

1. 从 s_k 重算必要的物理残差/局部块，得到 d_phys。

2. 更新状态与关系特征，运行条件化 tokenizer、super-token encoder、decoder、类型 head。

3. 融合 d_phys 与 d_net，应用验证过的松弛/步幅规则，生成提议。

4. 经过几何检查，并按已定义的数值接受规则处理候选；在候选状态上执行有界辅助量更新，记录截断、完整残差与更新尺度。拒绝试探不提交历史。
K 轮后原子提交一次时间步。中间轮是同一离散问题的修正，不是 K 个物理时间步；材料演化、关节累计角和摩擦状态遵守各自生命周期。网络调用数、检测预算与数值重试次数分别计数。

首版 K=2；在相同起始状态与目标下比较 K=1/2/4/8，其中超出训练预算的结果单列为外推压力测试。各轮共享权重；暂态 latent 每时间步清空，真实物理历史、接触历史和登记的数值热启动状态分别持久化。若提供迭代位置特征，须验证改变 K 不产生不合理响应或在已收敛候选上重新注入运动。

训练 loss 作用于融合并接受后的 rollout 状态；额外监督力位移/关节/接触响应。优先让 d_net 学习局部物理基线的剩余误差，不要求网络重学完整解析外力。

首版对碰撞集合、DAT 分隔构造和局部块 B 的构造停止梯度；保留几何更新对运动提议的已验证分段导数，并检查物理残差 g 的导数是否可用。若某物理算子完全停止梯度，必须记录为近似反传，缩短 rollout 并用监督补足，不能宣称端到端精确梯度。对 solve 的输入导数采用已验证实现，避免不必要反传高阶 Hessian。

### 4.11 自适应权重的第二步改造

FiLM 通过之后，再在关系 FFN 和 decoder FFN 添加低秩调制：
W(z) = W0 + A diag(g(z)) B，初始 rank=8。
生成 g(z) 而非整张权重矩阵，不为每个粒子复制完整参数。按对象/关系组分组计算；需要逐元素调制时评估带宽与显存。

物理材料参数是条件器的真实输入；全局共享 checkpoint 包含主干、条件器和类型 head。可缓存静态材料条件，但材料/环境/dt 变化时失效。

先不调制所有 Q/K/V；先确定 FFN 调制的收益与开销。用等参数量的 FiLM/固定权重模型做对照。跨材料泛化和参数可控不因采用 hypernetwork 自动成立。

### 4.12 Agent 实现顺序与模块验收

A1（P0–P1）：冻结源码、支持范围、离散目标、单位、状态生命周期与数据标签定义。
A2（P2）：构建最小异构 packed state 和纯局部物理基线；软体、布料、两个关节刚体及少量 rod 均先验证接口、DOF 和局部响应，无需复杂接触。
A3（P3）：独立验证几何层；按碰撞对/轨迹类型逐项打开能力。
A4（P4）：接类型 tokenizer/head、FiLM、共享 super-token encoder/decoder、全分辨率关系旁路和 K 轮 DAT；从小规模多类型数据训练一个 checkpoint。
A5（P5）：先验证物理参数、根保持、单位/分辨率与隔离，再比较低秩条件化和架构变体。
A6（P6–P8）：长 rollout 与离线数据聚合，扩展固定清单内全部关节及 rod/附件行为。
A7（P9–P10）：复杂多类型耦合、规模优化及冻结后的正式替代验收。

模块验收覆盖张量契约、自动微分检查、正确参考状态的内力、自由运动、受控参数扫描、反作用、姿态路径与成本。P2 即构建局部物理更新块，P4 将网络接入；P5 做条件化和结构验证，不再延迟引入物理分支。以上模块任务均未执行。

### 4.13 固定点、双向响应、场景隔离与尺度

**固定点与迭代一致性。** 对固定 s_t、h、控制和历史，取同 h 教师收敛得到的候选 y* 及相容辅助变量：再次执行共享更新块应产生容差内的零更新。这里指同一时间步离散方程的根，不要求运动物体在下一物理时间步静止。完整残差 r 必须含动力学、柔顺定律和所需接触/辅助方程，不能把未计约束力的 g 或有限刚度几何偏移直接当零目标。

P4 比较自由修正与根保持修正，例如基于完整归一化残差的无偏置映射，或 d_net = a(||r_C||) S tanh(head)，其中 a(0)=0，S 是明确的 DOF 物理尺度，r_C 覆盖当前交互分量全部所需残差。门控必须检验小残差有效运动是否被不当压制；只对局部不完整残差门控可能漏掉耦合。此结构只提供正确残差定义下的零点保持，不证明收敛、能量稳定或增加 K 必然更准确。验收包含静态平衡、运动中的已解候选、K=1/2/4/8 的漂移和动态响应。

**作用与反作用。** 先在无外力两物体相互作用测试线动量、角动量和载荷传递。可比较实体自由修正 head 与“预测关系响应、经关联 DOF 的转置 Jacobian 分配”版本；后者也需检查客观性、力矩和积分误差，不能仅凭成对输出就宣称整体守恒。所有统计在网络、局部物理、DAT 和速度恢复后进行，因为几何截断可能改变动量。

**力与冲量可观测性。** 支撑力、拉力、驱动力及接触冲量必须说明获取方式：独立测力边界/约束反力、与所选积分器一致的动量收支，或有明确关系归属的预测量。若只能由状态变化得到总广义响应，不能把它唯一分解为接触力。分别记录解析分支、网络修正和几何接受带来的响应变化；不能用解析支路力冒充整步总力。

**场景隔离。** 同一系统单独运行、与其他系统拼 batch、追加足够远且本步无物理作用的对象、重排节点/对象及重新编号时，对应轨迹应在数值容差内一致。测试覆盖 token 合并、attention、条件编码和归一化。与接触有关的 mask 必须按保守运动包络更新；新对象真正进入交互范围后允许且应当改变响应。任意对象 ID 只能用于索引与隔离，不能成为材料或场景记忆的捷径。

**单位与离散分辨率。** units_and_materials.md 定义长度、时间、质量及转动尺度，材料到单元能量/刚度的换算。优先使用可解释的无量纲特征，例如按质量度量缩放的 h²K 与惯性之比；不可直接将 E 当作单元 K，零质量/运动学 DOF 另处理。平移与转动块先做一致尺度变换。增加三类测试：同一物理问题更换单位后换回结果一致；同材料/几何细化网格后宏观响应收敛；按明确物理缩放规则改变尺寸后与参考响应一致。归一化不能消除真实刚度/质量/时间步依赖。

### 4.14 同步更新稳定化与有界接受规则

同步局部更新不同于 VBD 的着色顺序更新，不能直接继承其收敛性质。即使整体 Hessian 与各局部块均正定，不带松弛的同步块更新也可能放大误差；网络相加后，提议甚至可能偏离下降方向。DAT 只约束几何可行性，不能消除这一数值问题。

**P2 首版决策。** 将同步局部更新视为明确的新迭代法。先在无接触二次问题、受控弹性场景和简单关节场景中扫描松弛 omega，再选择有限支持域内可用的固定配置。对线性二次基准，可检查迭代矩阵 I − omega D⁻¹H 的谱半径；该条件只用于此类基准，不推广为非线性接触系统的收敛证明。

一个诊断反例：H 的对角元素为 1、非对角元素为 0.75，初始 x=(1,1,1)，E(x)=0.5 xᵀHx。H 正定且对角块为正，使用 D=I、omega=1 同步更新后，E 从 3.75 增至 8.4375。将该类反例纳入回归测试，避免误把“局部正定”作为整体稳定的充分条件。

**候选接受。** 定义稳定化与接受策略并计入预算。保守子问题可检查同一时间步的离散目标函数；含摩擦、驱动和辅助变量的问题采用与离散规格一致的完整残差/模型专用判据。不得把机械能逐轮下降作为通用要求，也不得宣称任意残差范数都必须逐轮单调。

若启用有界缩小步幅，预先固定尝试次数和评价成本；每次改变提议都重新遵守几何路径合约，检查最终几何处理后的候选。无法通过时按失败规则返回，不无限 line search、不启动完整 VBD。首版可只使用验证过的固定松弛加步末诊断，但必须报告支持域和失败率，不能宣称普适稳定。

**P4 新增验收。** 在同一离散问题上比较物理基线与融合模型的残差、目标值（适用时）、步幅、截断、K 扫描和长期响应；检查网络是否破坏已解候选固定点。动力学检查与几何检查分别报告。交付 numerical_acceptance_spec.md、松弛配置与最小不稳定反例。

## 5 可行更新与无穿透的证明责任

### 5.1 安全合约

可声明的保证必须写成条件命题：
初始状态合法；碰撞对完整；几何厚度与过滤规则正确；检测之间运动预算有效；刚体旋转及所有中间路径由保守方法覆盖；数值容差和失败策略已定义；每次更新遵守已证明的 DAT 或等价条件，则返回的接受路径保持指定几何的可行性。

经验零失败不等于证明。必须交付 safety_contract.md，逐项列出理论条件、实现对应、测试和未覆盖类型。初始已穿透时拒绝或进入单独修复流程；修复流程不属于持续无穿保证。

碰撞缓冲溢出、未支持几何、非有限数、预算失效时必须 fail-closed：重建/扩容、回滚、缩步或报错。不能漏掉候选后继续声称安全。

无表面相交、满足指定厚度/安全间距与无四面体反转是不同性质，分别验证。物理厚度、接触偏置 margin、候选检测范围 gap、可视化半径和数值容差必须分开；P0 核对固定版本的合成规则。允许的接触偏置压缩不自动等于允许几何穿透，候选 gap 也不能当实体厚度。DAT 不自动保证摩擦准确、不可压缩性、能量或动量。

### 5.2 更新从哪里开始

固定时间步 t 的当前合法状态 s_t 是可行更新起点。外力预测状态可以作为网络目标信息，但不能未经检测成为新起点。内部 k 轮迭代不重复积分完整时间步外力。

将输出速度与位置更新的一致性作为显式设计：

- 初版使用与教师一致的离散速度重建和旋转速度定义；

- 若保留独立速度 head，必须进行接触速度处理和一致性验证；

- 不能只截断位置而原样接受指向障碍物的速度。

### 5.3 关节与刚体

初期采用接近 VBD 的最大坐标，刚体以 SE(3) 合法姿态更新；关节按固定版本的力学定律进入残差。区分理想几何关系、有限刚度下的物理偏移、离散方程的数值残差和驱动跟踪误差。柔顺关节/附件受力后的偏移应匹配其力位移或力矩角度关系，不强制压到零；只有模型确为硬约束的分量才采用几何约束容差。有限预算不意味着严格满足硬约束，也不得为消除偏移而改变原物理刚度。

禁止先 DAT 后未经检查投影关节。所有改变几何的修正必须经过可行路径检查。联合约束不相容时应报告，不得循环直到穿透。

首版采用最大坐标对齐所锁定 VBD 的关节语义。广义坐标仅作为清单内关节的可选实现研究，不引入新的关节类型或额外能力要求；若采用，须验证曲线运动路径，不能用终点间直线 CCD 冒充覆盖。限位、附件以及连接约束只按 joint_scope.json 中 VBD 已支持的行为建立合约。

### 5.4 微分策略

先实现纯前向且独立验收的安全层。第二步固定接触集合和分隔几何，对连续截断算子求分段导数；分支切换处不声称光滑。

对小型非退化算例做有限差分梯度检查。原生 Warp/PyTorch 无法传梯度时实现明确的 custom autograd，不得默认自动可微。stop-gradient 或代理梯度只能影响反向，前向不得使用软化安全规则。

激活约束导致梯度饱和时，对网络原始提议添加与同 h 目标一致的监督；同步监督接受后的运动和切向响应，防止零位移策略。教师中间更新若依赖 VBD 着色顺序，不直接当作同步网络块的逐轮标签。

### 5.5 按碰撞组合与实际路径逐项证明/验证

建立 collision_coverage.json；每一项记录几何原语、过滤、两侧运动、轨迹模型、保守界/检测实现、数值条件及独立验证器。状态为 PROVED_UNDER_CONDITIONS、EMPIRICALLY_TESTED 或 UNSUPPORTED；经验通过不得升级为条件证明。

| 碰撞组合 | 必须覆盖的风险 | 开放条件 |
| --- | --- | --- |
| 软体/布料对静态几何 | 点面、边边、表面厚度、退化三角形、过滤 | 对所用原语和路径有完整候选及保守接受条件 |
| 软体/布料之间与自接触 | 双方同时移动、折叠、近邻排除、薄片双面 | 所有相关运动纳入同一检测/截断；不能将一方视为静止 |
| 刚体—软体/布料 | 旋转曲面轨迹、对方变形、高速掠过 | 刚体保持刚性，整个旋转路径有保守覆盖 |
| 刚体—刚体 | 双方平移和旋转、高角速度、薄特征 | 对双方轨迹共同验证；粒子测试不能代替该项 |
| rod/cable 与各类物体及自接触 | 有限半径、弯曲/扭转、端点附件、交叉 | 按真实使用的杆/胶囊/表面几何验证；中心线不交叉不足够 |
| 运动学物体与以上对象 | 外部规定运动、瞬间跳变、不受网络截断的轨迹 | 预先给定连续且可处理的路径；无法满足的命令拒绝或判超支持域 |

刚体旋转不能仅检查首尾姿态，或靠有限采样加二分就宣称覆盖连续路径；需要区间保守包络、可验证距离界或已证明等价机制。若采用 DAT 原文的刚体扩展，必须复现其完整保守条件，而非只搬运粒子截断公式。四面体反转采用独立体积/行列式路径条件。

**区分求解路径与时间轨迹。** K 轮可行更新构成求解器内部路径，其参数不是物理时间。API 必须声明返回何种轨迹：只有端点、分段接受路径，还是实际时间内的位姿插值/子步路径。内部路径可行不保证直接连接起终点的另一条插值可行。正式“持续无穿”声明必须覆盖下游实际采用的路径；若只保证端点及内部路径，就如实限定。需要连续回放、运动学耦合或路径上的传感器时，对相应时间参数化单独验证，并说明与速度/积分器的关系，不将任意求解轨迹冒充真实运动轨迹。

### 5.6 网络展开与几何运动预算的相容性

分别配置 K_net（网络调用次数）、J_detect（检测刷新及其有效运动区间预算）、max_geometry_trials（几何处理/重试上限）和 h（物理时间步）。文中其余位置的 K 指 K_net；不得默认每次网络调用都自动获得新的几何运动预算，也不能反复清零累计位移计数而不刷新检测参考。

若沿用当前 Newton 刚柔 DAT 的保守预算，需在 P0 核对固定实现：两次检测之间各侧可移动范围与查询半径及松弛有关，并可能限制当前远离软几何的动态对象。该策略属于具体实现的预算，不是所有 DAT 变体都必须使用的统一公式。

**必要的容量检查。** 对某个平移自由度，若第 j 个有效检测区间最多允许路径长度 b_j，则可达位移不超过 Σ_j b_j。若正确自由运动要求的 |v|h 已超过这个上限，网络增加输出幅度也不能完成目标。刚体旋转还需按表面点轨迹界检查，不能只看质心。

示例仅用于说明预算：假设每区间允许 0.5 × 0.85 × 0.01 m，有 2 个有效区间，则总位移上限为 0.0085 m；若目标是 0.1 m，该配置存在容量冲突。这不是实际性能数据。

P3 增加高速自由运动、已知可行平移/旋转和教师合法分段路径的预算回放。记录运动预算利用率、截断原因、检测刷新次数与残余误差；检查首版固定 h、几何半径、速度/角速度范围及 K_net 是否相容。单一朝向教师终点的提议被截断，只能说明该路径/方向受限，不能据此证明所有路径不可达。

若存在系统性容量不足，调整查询范围、检测频率或已支持 h，并计入新增成本；随后重验几何完整性与动力学。若独立增加几何分段，必须明确它只是接受路径细分还是物理子步，不能暗中重复施加整步外力。

交付 motion_budget_spec.md 与 reachability_report.json。此门槛在大规模训练前完成，禁止把运动预算不足误判为网络容量不足。

参考：[Newton SolverVBD DAT 运动预算与路径说明](https://newton-physics.github.io/newton/latest/api/_generated/newton.solvers.SolverVBD.html)。

## 6 分阶段训练与替代路线

各阶段输出代码 commit、配置、数据 hash、测试明细、分项计时、失败复现和晋级判断；有训练的阶段另交 checkpoint 与训练/验证曲线，无训练阶段明确写 N/A。某阶段不过就修复当前问题，不能靠扩展功能掩盖。能力只在其动力学与对应几何覆盖均通过后开放；算法、训练和性能结果不得以计划文字替代。

### P2 最小异构接口与局部物理基线

依赖 P0/P1。先实现 packed state、关系 schema、局部残差/度量与固定预算的小块更新；同时覆盖小软体、小布料、两个以清单内关节相连的刚体及数段 rod。先无接触，必要时仅使用已单独验证的简单边界。

训练：无；此阶段不要求先复现纯神经预测器。

推理：仅运行新建局部物理分支及合法姿态更新，作为之后的物理基线；不接完整 VBD。

验收：单位/shape/mask、重启状态一致、局部力与导数、参考状态、自由运动、柔顺力位移、驱动评价时刻和 rod 帧正确。有限预算与同 h 收敛参考的差距明确可测，不要求局部基线已经解决全部全局耦合。

性能：测物理、状态转换及候选构建成本，建立 time_budget.json 与初步规模曲线；若解析/几何固定成本已吃完目标预算，先调整范围/实现再训练。

新增门槛：按第 4.14 节验证同步更新松弛和候选接受策略，包含局部块正定但完整同步步失稳的反例；关节历史按第 3.3.1 节验证。

交付：numerical_acceptance_spec.md、可独立运行的 physical_only 配置、最小多类型场景、state_lifecycle 测试和算子调用审计。

失败诊断：先修符号、单位、惯量/旋转、材料换算、残差定义和历史更新；不通过加大网络掩盖。

### P3 DAT 独立模块

依赖 P0/P1 的几何和离散规格，可与 P2 工程交错。输入任意甚至恶意提议，与网络训练独立；逐项执行第 5.5 节覆盖矩阵。

训练：无。

推理：仅几何接受/截断，记录候选完整性、双方运动包络、数值条件、截断及拒绝原因。

验收：先通过软体/布料与静态/柔性几何的子集；刚体、rod、运动学物体必须分别验证，未完成项保持 UNSUPPORTED。P4 使用哪一项，该项就须先通过；P7/P8 不自动继承未完成的证明。

新增门槛：执行第 5.6 节的运动预算可达性检查，分别冻结 K_net、J_detect、几何尝试预算和首版 h；确认正确自由运动不会被配置系统性截短。

交付：motion_budget_spec.md、reachability_report.json、safety_contract.md、collision_coverage.json、独立路径检查器和高速/旋转/薄几何/退化/溢出压力测试。

失败诊断：核对漏检、过滤、厚度、预算复用、旋转轨迹、初始状态及对外插值；禁止以增加接触 loss 修复几何缺陷。

### P4 共享混合网络与训练内 DAT

依赖 P2/P3，且本版稳定化、运动预算、关节历史三项检查通过。按第 4 节接类型 tokenizer/head、参数 FiLM、共享 super-token 主干、关系旁路及物理—网络融合；从最小多类型集合训练一个 checkpoint。先拟合 8–16 条诊断轨迹，再扩展 pilot；未验证接触的类型保留无接触训练。

训练：固定 h、同 h 教师，先单步再短 rollout；在相同架构上比较无 DAT、仅推理 DAT、训练/推理 DAT。无 DAT 对照只在独立实验中运行，不作为保证路径。

推理：K=2 起步，物理分支与网络读取同一候选快照；驱动依赖候选状态时重算；全部接受与历史提交遵守统一契约。

验收：材料响应、最小异构任务、批次/对象重排隔离、已解候选零更新、速度一致性、累计关节角连续性、数值接受策略、几何合约和完整 VBD 入口禁用测试。比较自由修正与根保持修正，测 K=1/2/4/8，并分别统计检测/几何处理次数；训练内 DAT 应降低不必要截断/卡死且不靠缩小整体运动取巧。

性能：立即测总成本及对仅物理、仅网络、融合的误差—耗时曲线；如果网络没有可测的耦合/响应收益，或预算明显不可达，暂停扩大模型和数据。

失败诊断：条件输入被忽略、梯度饱和、尺度混乱、教师冲突、重复受力与未建模历史优先排查。

### P5 物理参数控制与网络结构定型

依赖 P4。固定小规模共享模型，系统验证可控性和泛化，不到此时才接入物理分支。

训练：增加同几何/同初值/同载荷的成对材料扫描，分开物理参数插值、参数组合和范围外外推；保持每类任务回放。先验证拼接/FiLM，再比较低秩条件化，并做等参数量及总成本对照。

推理：继续用同一共享 checkpoint 和有界展开；物理参数通过对应实体/关系的条件编码改变响应，不切换类型专用模型文件。

验收：静力曲线、振动频率/衰减、关节柔顺响应、单位转换、网格细化、尺寸缩放、场景隔离与固定点测试通过。对 K、摩擦/质量比/刚度比作验证集扫描，冻结后续支持域和数值配置。

消融：物理方向、物理特征、局部度量、网络修正、残差门控和关系响应 head 分别比较；网络必须产生可测收益，不只增加参数或用几何保护掩盖错误动力学。

失败诊断：先查材料到离散参数换算、数据覆盖和损失单位；低秩调制若无收益则保留 FiLM，不强行增加架构复杂度。

### P6 新求解器独立长时推进

依赖 P5。检验共享网络与物理算子在自身预测状态上的长期响应。

训练：新求解器生成训练 rollout；完整保存合法状态及历史，离线查询同 h 教师演化并加入数据集。评测轨迹不调用教师、不写回教师修正；教师查询失败的数据单列诊断。

推理：仅新求解器独立推进；增加 K 或子步只能使用已训练/验证且预算明确的配置，不切换完整 VBD。

验收：软体、布料及已有简单刚体/rod 长 rollout；完整求解器入口禁用后运行；动态平衡、耗散、接触粘滑、状态重启一致。拒绝、卡死、冻结、缩步与超预算全部计入统计。

性能：给出误差—时长—总耗时曲线及最坏接触负载；局部运算、网络、几何和重试费用分别计入。

失败诊断：先检查重复力/冲量、物理历史重复推进、摩擦匹配、速度恢复和网络固定点漂移。

### P7 刚体与 VBD 支持的关节

依赖 P6 及相应刚体碰撞组合的几何验证。在 P2/P4 已有 body/joint 接口上，逐项补全 joint_scope.json 的类型、参数、限位、驱动与组合行为；不扩展固定 VBD 版本之外的机器人功能。

训练：自由平移/旋转、摆、加载柔顺性、驱动跟踪、限位及接触冲击；对每个支持项建立教师行为对照。

推理：连杆进入同一图。外部控制器按控制周期采样命令，K 轮内保持命令不变；PD/隐式驱动力依离散模型在候选姿态/速度上重新评价。明确控制周期与仿真 h 的关系。

验收：刚体不变形、姿态/惯量正确、柔顺关系与数值残差分开达标、反作用及驱动做功一致；刚体旋转连续路径合约通过。驱动饱和/限位等只实现固定源码实际支持的语义。

失败诊断：先查坐标系、角速度、作用点、动作时间对齐和驱动力冻结错误。不把其他 Newton 求解器支持视为 VBD 支持。

### P8 Cable 和附件

依赖 P7 及 rod 相关碰撞组合的几何验证。在已有 rod 接口上完善段朝向/角速度、参考帧及源码支持的拉伸、剪切、弯曲、扭转参数；实现 joint_scope.json/能力矩阵内的端点附件。

训练：受控拉伸、弯曲、扭转、剪切、打圈、自接触和加载附件；逐项材料扫描。

推理：rod、附件及接触进入同一共享图和迭代；不运行独立 rod 模型，不将所有附件硬化为零偏移约束。

验收：力伸长、力矩扭角、悬臂、长度变化、参考帧、柔顺附件的载荷偏移及有厚度自接触通过；力/冲量的观测来源明确。

失败诊断：中心线正确但扭转错误时检查朝向 DOF、参考帧和离散刚度换算；端点偏移先判断是物理柔顺还是数值误差。

### P9 复杂混合耦合与规模扩展

依赖 P6/P7/P8。沿用 P4 起建立的共享 checkpoint 扩展复杂混合场景，不到此时才首次合并各类型网络。类别均衡采样并回放旧任务。

组合顺序：刚体—软体、刚体—布料、刚体—rod、柔柔，最后机器人—rod—软体/布料；每种组合先验证其碰撞覆盖与受控双向载荷传递，再扩展动作和接触密度。

训练：补充交互数据、多材料交界和接触切换；按类型/尺度分项归一化，不为每个场景生成独立 checkpoint。

验收：同一 checkpoint 服务所有开放功能；双方反作用、加载形变、滑移/摩擦、任务结果和断开交互后的隔离达标；单系统无明显遗忘。

性能：扫描 DOF、接触数、对象数、质量/刚度比及 token 数，报告总时延/显存和最坏预算；缩步与拒绝不能从计时中删掉。

失败诊断：先查交互关系与历史覆盖、单位/采样/损失，再考虑有限类型 head；不只增加孤立对象数据。

### P10 扩展与正式替代验收

依赖 P9。冻结 checkpoint、数值预算、支持域和验收阈值后，独立测试未见拓扑、分辨率、摩擦组合、动作、质量/刚度比、长链及密集接触。机器人项目严格限于 joint_scope.json；不增加额外关节或高级约束要求。
同时报告：对同 h 收敛教师的求解误差；对小 h 参考的物理/时间离散误差；与生产预算 VBD 在匹配精度和仿真时长下的性能曲线。
交付推理 API、模型/数据卡、安装与复现说明、单步失败语义、状态/路径契约、兼容矩阵及算子成本清单。
只对新求解器独立步进完整达标的功能声明“替代 VBD”；无穿保证按几何组合和实际路径限定。未达标功能标实验中或不支持，不启用完整 VBD 兜底。

## 7 训练规范

### 7.1 初始超参数

以下仅是 pilot 起点：共享宽度 128 或 256，少量 encoder/decoder 层；K=2 起步、1/2/4/8 作预算和外推对照；AdamW 学习率 1e-4、梯度裁剪 1；按 token 数限制 batch，关键结论用三个随机种子复验。原始 WorldParticle 复现与改造后小模型分开报告。最终 K 与结构由总成本、固定点和响应测试选择，不假定展开越多越好。

先用 FP32 建立正确性，独立验证器采用更高精度或保守算法。混合精度仅用于网络；几何保护不得未经测试降精度。先完成小场景拟合，再根据学习曲线扩数据和模型。

### 7.2 课程

1. 单步、固定 h、有限材料范围，从最小多类型共享集合起步；无接触与已通过几何验证的接触分开推进。

2. 短 rollout：2、4、8、16 步逐级增加，以验证门槛晋级而非固定 epoch。

3. 接触密度、材料比、动作变化逐级增加。

4. 在新求解器自身 rollout 状态上做离线教师查询与数据聚合，保存完整历史；查询轨迹属于训练数据，不用教师修复正式评测轨迹。

5. 多类型平衡训练和旧任务回放。

6. 最后研究可变 dt、网格变化和严格域外。

每个 epoch 分开记录类型、接触/非接触、材料参数区间表现。不要只保存平均 loss 最小 checkpoint；必须同时满足安全实现、物理和参数控制验证。

### 7.3 损失

总损失候选：同 h 教师的状态 rollout、位姿/角速度、相容的原始提议监督、柔顺力学/完整数值残差、驱动响应、接触响应、运动一致性与截断代价。小 h 参考主要用于独立物理评测；若要以其为训练目标，须另建清晰的目标模型/消融，不与原大 h 零残差硬性混用。硬约束、有限刚度偏移和跟踪误差使用不同 loss，不能统一压到几何零。

所有项先定义单位、归一化与标签来源，在验证集调权后冻结。旋转误差用 SO(3) 测地距离；动量收支包含网络和 DAT 后的实际更新，外力/边界/驱动冲量应计入。能量在驱动、摩擦或阻尼下按功与耗散评估，不强制守恒；粘滑与摩擦耗散单独测。只有可识别的力/冲量才进入相应监督，不能用解析支路力作为整步真实标签。

截断损失仅辅助效率。优先监督实际物理推进，防止模型以零提议满足无截断。若使用 stop-gradient 教师目标或截断目标，在实验配置中明确记录。

### 7.4 材料输入的验真

固定形状、载荷和边界只改一个参数；同时扫描密度与刚度以避免只学习 E/rho 的某个偶然相关性。验证参数灵敏度与教师一致，但不能要求任意动态场景位移随 E 全局单调。单调性仅用于确实成立的受控静力实验。

若使用超网络，检查参数改变是否改变有效权重及物理曲线；若性能提升仅来自更多参数，不能归因于条件化。区分未见参数插值与范围外外推。

### 7.5 资源预算

P0/P1 测教师各类生成 1000 步的耗时和轨迹大小；P2 测局部物理/几何成本；P4 有小模型后再测每训练步耗时、显存及端到端推理。先用 pilot 估计学习曲线，再锁定 max_gpu_hours、max_disk_gb、max_runs；达到预算保存 checkpoint 与报告。本方案不假定 GPU 数量，也不授权额外付费资源。固定物理/几何成本或小模型成本已超过目标预算时，先缩小支持域或改实现，不继续盲目放大训练。

## 8 推理流程与运行时合约

建议 API：step(model, state, control_command, external_inputs, dt) -> next_state, diagnostics[, accepted_path]。model 保存静态几何、物理配置和共享网络；state 保存第 3.3 节全部持久状态。external_inputs 区分应冻结的量与在候选状态上求值的力模型，禁止用接口含糊掩盖控制语义。

材料/拓扑/接触过滤变更按 state_schema 使相关缓存失效。diagnostics 返回接受/拒绝、K_net、检测刷新数、运动预算利用率、松弛/数值接受结果、各类算子及辅助量更新次数、缩步/重试、完整残差、柔顺响应误差、最小几何间距、候选溢出、截断比例和分项耗时。accepted_path 必须注明参数化及保证范围；仅返回端点时不得暗示任意下游插值均安全。部署依赖不创建或调用完整 VBD 求解器。

伪代码：

1. 校验当前状态、参数范围、几何和模型支持范围。

2. 保存全部状态及历史快照；采样本控制时刻的命令/目标，按离散规格预计算应冻结的外力和惯性目标。状态相关驱动力/阻尼不在此永久冻结。

3. 从当前合法状态初始化内部解；建立完整保守碰撞候选和预算。

4. 对 k = 1…K：

   - 从同一候选快照及时间步起点历史计算惯性、本构、驱动、关节和接触残差/局部度量；执行固定预算小块响应，候选相关力按规格重算；

   - 类型 tokenizer、条件化 WorldParticle 和类型 head 计算耦合修正，与局部物理提议融合并施加已验证松弛；

   - 使用合法旋转/自由度更新表示；

   - 按独立的检测/运动预算检查所有对象路径，必要时在预算内重检测；核对第 4.14 节数值接受规则，每次重新试探仍受同一几何合约约束；

   - 在候选副本上更新有界数值辅助量及关节分支，记录截断与完整残差；拒绝试探不污染持久状态，不重复累计材料演化或累计关节角。

5. 按同 h 教师离散规则恢复速度/角速度，在候选副本上评价一次材料、关节及摩擦历史；通过第 6 步检查后才在第 7 步原子提交。任何进一步几何修正仍须检查。对外采用不同时间插值时，单独验证该路径及其速度语义。

6. 独立检查数值、支持范围、完整残差、柔顺响应/硬约束各自的标准、累计角/转角支持范围、几何诊断、运动预算和总成本；不能因柔顺偏移非零便判失败，也不能以无穿透代替动力学验收。

7. 成功则原子提交整步；失败则回滚全部状态、历史和时间，在已验证且封顶的新求解器预算内重试或返回失败。不得调用完整 VBD/IPC 动力学求解器，也不提交非法或未验证状态。

只可切换已训练/验证的 K 档或 h 子步配置，重试次数、总物理算子次数及总时间预算提前固定；子步控制/外力采样遵守控制时钟。仍失败则返回失败，不能无限加 K 演变为隐式的完整收敛求解。冻结状态和部分推进不算成功完成请求时长。完整教师仅由离线工具访问。

缩步必须同步动作、外力、控制器时序和剩余时间；可变 dt 未训练时不能默认预测正确。测性能计入网络、解析积分、本构/残差、小块求解、几何可行层、重试和缩步的全部成本。

预测不确定性可帮助选择预算，但不能代替几何验证器。即使置信度很高，也不得绕过安全合约。

## 9 验收指标和建议门槛

下表是初始工程建议。P1 定义指标/尺度，P4–P5 用训练/验证集校准可执行阈值并在正式测试前冻结；测试后不得为通过而放宽。记录均值、中位数、p95、最坏值和逐场景结果。必须分开同 h 求解误差、小 h 参考偏差、物理柔顺位移和数值误差。

| 维度 | 度量 | 初始建议/判据 |
| --- | --- | --- |
| 几何 | 已声明实际路径的相交、厚度违规、反转 | 支持域内零违规；各项保证、保守容差及未覆盖组合单列 |
| 数值 | NaN、Inf、漏失/溢出后继续运行 | 零容忍 |
| 节点状态 | 对同 h 教师的位置 RMSE/固定参考长度 L | 短 rollout p95 小于 1%、长 rollout 小于 3% 为 pilot 目标，按任务预先冻结 |
| 刚体 | 质心误差/L、SO(3) 角误差 | 角误差 p95 小于 1 度为 pilot 目标；另测转动响应 |
| 硬约束分量 | 仅对模型确为硬约束的平移/角残差 | 1e-3 L、0.5 度为初始几何容差，不用于柔顺分量 |
| 柔顺关节/附件 | 载荷—偏移、力矩—角度关系及同 h 数值残差 | 与固定物理刚度参考比较；允许正确的非零物理偏移 |
| 驱动 | 目标采样、跟踪、限位及做功 | 区分控制误差与求解误差，逐项对照固定 VBD 语义 |
| 材料控制 | 静力曲线、振动频率、衰减 | 受控实验相对误差约 5% 为起点 |
| 耦合响应 | 可识别的支撑/拉力、冲量、滑移及任务结果 | 明确观测来源、参考种类及误差预算；不能只测解析支路 |
| 结构一致性 | 已解候选零更新、K 扫描、场景隔离、单位变换、网格收敛 | 数值尺度容差/物理响应阈值预先定义；不得出现系统性非物理漂移 |
| 可靠性 | 拒绝、卡死、冻结、缩步、超预算 | 正式域内集目标零拒绝；完整 VBD/IPC 求解调用为零，有界局部调用单列 |
| 效率 | 同硬件、匹配精度、相同模拟时长的总耗时 | 至少 2 倍是研究目标；未达标不宣称该倍数，加速结论以实测为准 |

L 必须是固定的物理参考长度，不能用整个大场景包围盒稀释局部误差。厚度/间距误差额外以最薄几何尺度归一化。速度归一化使用预先定义的非零参考速度。

短 rollout 默认至少 100 步；长 rollout 默认至少 10000 步，且报告对应物理秒数。混沌轨迹长期逐点偏差不一定等于错误，应同时看统计分布、任务表现和守恒/耗散，不以此免除短期准确性。

几何测试至少覆盖 1000 个随机压力场景，并报告实际检测事件数量。零观察失败仅是经验结果，证明责任仍由 safety_contract.md 承担。


性能：GPU 同步计时，编译/预热单列；同硬件、数值精度、输出频率、模拟时长，禁用渲染。总成本包括碰撞、候选/特征、条件编码、网络、物理算子、DAT、历史更新、转换和同步；重试/缩步全部纳入。报告 p50/p95/最坏延迟、吞吐、显存及 DOF/接触数变化。高精度教师耗时不能替代生产 VBD 的公平基线，须比较双方精度—成本曲线。

#### 9.1 在扩展前通过的三道门槛

**P2 固定成本门槛：** 测量纯局部物理、状态转换与几何模块。在既定任务尺度下，估计可留给网络的预算；无法容纳网络时先优化或收缩范围，不启动大规模训练。

**P4 小模型价值门槛：** 比较仅物理＋DAT、仅网络＋DAT、融合＋DAT，在相同数据和明确计算预算下的响应误差、卡死/拒绝率及总时延。融合模型应在精度—成本上产生可解释收益；单纯增加 K 或依靠高频子步的提升必须计费，不算网络自动加速。

**P5 扩展门槛：** 物理参数控制、固定点、场景隔离、单位/网格测试及至少一组双向耦合全部通过后，才扩大模型与数据规模。任何模块优化必须重新核对相关能力和几何合约。

time_budget.json 记录碰撞/图构建成本、每轮物理＋网络＋DAT 成本、固定开销与最坏重试预算。主项可写成 T_step ≈ T_build + Σ_k(T_physics,k + T_network,k + T_DAT,k) + T_commit，但实际重检测/子步必须据实归入；不假定各轮耗时恒定。P2/P4 就画出预算分解，P9 再验证规模扩展。

另外记录 K_net、J_detect、max_geometry_trials、松弛与接受检查次数。分别改变网络次数和检测频率做对照，避免把增加几何预算的收益归因于网络。

## 10 消融和关键风险

必须消融：材料输入有/无；拼接/FiLM/低秩调制（等参数量及总成本）；局部接触旁路有/无；仅推理 DAT/训练内 DAT；单次/共享展开；物理残差特征有/无；独立类型基线/共享 checkpoint；离线数据聚合有/无；K=1/2/4/8。主对照是仅网络＋DAT、仅局部物理＋DAT、融合＋DAT，分开消融物理方向、局部度量和网络修正。新增自由加法/根保持修正、实体输出/关系响应分配、物理交互 mask/全场景 attention 对照；报告平衡漂移、作用反作用、隔离及全成本。消融中未通过几何机制的配置只作实验，不输出保证声明。

主要风险与动作：

- 注意力或固定物理成本比 VBD 更贵：P2/P4 即 profile；按证据调整稀疏度、层数、token 数和调用频率。减少调用后重新验证动力学及候选完整性，不能只报网络 kernel 更快。

- 网络被 DAT 截断后卡死：检查方向与切向自由度、提议监督、训练分布；安全而不动是失败。

- 关节修正破坏无穿或错误硬化柔顺性：所有几何更新受同一合约；力位移关系按物理刚度评估。硬约束兼容路径只在固定支持范围内研究。

- 多材料泛化失败：检查逐单元属性、单位、载荷相关性和参数覆盖。

- 共享模型遗忘：类别平衡、旧任务回放、按类型报告；不通过就保持阶段未完成。

- 与教师一致但物理错误，或两个教师目标冲突：回到 P1，区分同 h 求解误差与小 h 时间离散误差，核对接触几何及历史相容性。

- 接触梯度不稳定：先固定活跃集，梯度检查；前向保持硬规则。

- 模型通过非物理耗散获得稳定：检查频率、能量、冲量、滑移。

- 命令与接触不可兼容：按固定 VBD 已支持的驱动柔顺/限位等语义处理；运动学规定轨迹无法满足几何条件时明确拒绝。不得擅自增加新控制功能或移动障碍。

- 路径只验证终点：加入连续路径/保守运动界验证，尤其刚体旋转和关节运动。

- 任意材料/拓扑/控制外推：返回 out_of_domain 标记，明确不属于已验收范围。

阶段暂停条件：几何合约缺口、教师不收敛/标签目标冲突、历史丢失、数据泄漏、明显固定点漂移/场景串扰、完整 VBD 步进或回退调用、时间预算超限。禁用完整求解器入口后，新求解器须独立运行；允许登记在册且预算明确的材料、积分、小块求解与辅助量更新。审计深入算子内部，防止只是改名封装完整迭代链。
